Přehled
Obrazovka pro nastavení tréninkového plánu hráče. Hráč si vybere až 4 TECH atributy (jeden per slot) pomocí OptionButtonů. Plán se uloží přímo do PlayerData.training_plan a scéna se vrátí na WeekScreen.

Logika — flow
_ready()
	1.	Připojí signály SaveButton a BackButton
	2.	Null check GameManager.player_data → pokud null, okamžitý návrat na WeekScreen
	3.	Naplní všechny 4 OptionButtony přes _fill_option()
	4.	Načte uložený plán přes _load_from_player_data()
_fill_option(ob: OptionButton)
Vymaže OptionButton a naplní ho pretty-name verzí všech _tech_keys. Defaultně vybere index 0 (Shooting).
_load_from_player_data()
Čte přímo z p.training_plan.
	•	Pokud training_plan je Array a má 4 položky → nastaví sloty podle uloženého plánu
	•	Pokud ne → výchozí stav: všechny 4 sloty = Shooting
_select_by_key(ob, key)
Najde index klíče v _tech_keys pomocí find(). Pokud klíč není nalezen, vybere index 0 (safe fallback).
_on_save_pressed()
	1.	Null check player_data
	2.	Sestaví new_plan: Array[String] ze 4 slotů
	3.	Uloží přes p.training_plan = new_plan
	4.	Přejde na WeekScreen
_on_back_pressed()
Přejde na WeekScreen bez uložení.
_pretty_name(key) -> String
Lokální helper pro zobrazení čitelného názvu atributu v UI.
