# GameManager.gd — Dokumentace
 
## Přehled
 
Globální singleton (Autoload) který řídí celý životní cyklus hry. Drží referenci na `player_data`, inicializuje novou hru a zajišťuje přechody mezi scénami. Jakýkoliv jiný skript v projektu může přistupovat k datům hráče přes `GameManager.player_data`.
 
---
 
## Soubor
 
- Soubor: `GameManager.gd`
- Typ uzlu: `Node`
- Registrace: Autoload singleton (nutno nastavit v Project Settings → Autoload)
- Stav: 🟢 Implementováno (rozšířená verze)

## Proměnné
 
| Název                       | Typ        | Výchozí | Popis                                                                 |
|----------------------------|------------|---------|-----------------------------------------------------------------------|
| player_data                | PlayerData | null    | Reference na aktuální data hráče. null dokud není zavolán new_game() |
| week_preview_total_matches | int        | 0       | Celkový počet zápasů v aktuálním týdnu (persist mezi scénami)        |
| week_preview_played_matches| int        | 0       | Počet již odehraných zápasů (persist mezi scénami)                   |
| match_sim_shooting_skill   | int        | 1       | Shooting skill předaný do MatchSimScreen před přechodem scény        |
 
⚠️ Poznámka: Proměnné `week_preview_*` a `match_sim_shooting_skill` slouží jako dočasný přenos stavu mezi scénami, protože `change_scene_to_file()` reloaduje scénu a lokální proměnné se ztrácejí.
 
---
 
## Metody
 
### `new_game(player_name: String, player_class: String) -> void`
 
Inicializuje novou hru. Vytvoří instanci `PlayerData` a zavolá její `setup()`.
 
| Parametr     | Typ    | Popis                                         |
|-------------|--------|-----------------------------------------------|
| player_name | String | Jméno hráče (po strip_edges z character_creation) |
| player_class| String | Vybraná classa (např. "Sniper")               |
 
⚠️ Proměnná pojmenována `player_name` (ne `name`) — Godot Node má vlastní property `name`, kolize by způsobila chybu.
 
---
 
### `change_scene(scene_path: String) -> void`
 
Interní helper. Zavolá `get_tree().change_scene_to_file(scene_path)`.
 
---
 
### `goto_character_creation() -> void`
Přechod na obrazovku tvorby hráče.
 
### `goto_week_screen() -> void`
Přechod na týdenní obrazovku.
 
### `goto_training_screen() -> void`
Přechod na obrazovku tréninku.
 
### `goto_week_preview_screen() -> void`
Přechod na WeekPreviewScreen (přehled zápasů týdne).
 
### `goto_match_sim_screen(shooting_skill: int) -> void`
Uloží `shooting_skill` (clamped 1–99) do `match_sim_shooting_skill` a přejde na MatchSimScreen.
 
| Parametr      | Typ | Popis                              |
|--------------|-----|------------------------------------|
| shooting_skill | int | Shooting atribut hráče (1–99)   |
 
### `reset_week_preview_state() -> void`
Resetuje dočasný stav týdenního přehledu:
- `week_preview_total_matches = 0`
- `week_preview_played_matches = 0`
- `match_sim_shooting_skill = 1`

## Edge Cases
 
| Situace                                  | Chování                                                              |
|-----------------------------------------|----------------------------------------------------------------------|
| Přístup na player_data před new_game()  | player_data je null → ostatní scény musí počítat s null checkem      |
| Neexistující cesta scény                | Godot vyhodí runtime error při change_scene_to_file()                |
| Volání new_game() opakovaně             | Přepíše stávající player_data bez varování — nutno zvážit reset flow |
| goto_match_sim_screen() bez předchozího nastavení | shooting_skill je clamped, takže min. hodnota 1 je vždy platná |
 
---
 
## Tok dat — jak GameManager zapadá do hry
 
character_creation.gd
    → GameManager.new_game(name, class)           # vytvoří PlayerData
    → GameManager.goto_week_screen()              # přechod na week_screen
 
week_screen.gd
    → GameManager.player_data                     # čte data hráče
    → GameManager.goto_training_screen()          # přechod na training
    → GameManager.goto_match_sim_screen(skill)    # přechod na simulaci zápasu
 
week_preview_screen.gd
    → GameManager.player_data                     # čte data hráče
    → GameManager.week_preview_total_matches      # persist stavu
    → GameManager.week_preview_played_matches     # persist stavu
    → GameManager.goto_week_screen()              # návrat po dokončení týdne
 
match_sim_screen.gd
    → GameManager.match_sim_shooting_skill        # čte shooting skill
    → change_scene na week_screen nebo week_preview_screen
 
training_screen.gd
    → GameManager.player_data                     # čte + modifikuje data hráče
    → GameManager.goto_week_screen()              # návrat zpět
