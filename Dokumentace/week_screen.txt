Logika — flow
_ready()
1.	Připojí signály tlačítek
2.	Volá _ensure_week_state() — inicializuje nebo obnoví stav zápasů z meta
3.	Volá _apply_return_from_match_if_needed() — zpracuje návrat z MatchSimu
4.	Volá _refresh_ui()
_ensure_week_state()
Detekuje zda jsme v novém týdnu nebo jen reloadujeme scénu.
•	Nový týden (saved_week ≠ current_week, nebo saved_season ≠ current_season, nebo saved_total ≤ 0): Vygeneruje matches_this_week = randi_range(1, 3), uloží do meta
•	Stejný týden: Načte uložené hodnoty z meta. matches_remaining = 0 je validní stav (všechny odehrány), NEgeneruje nový počet
_apply_return_from_match_if_needed()
Pokud meta "ws_returned_from_match" = true:
1.	Resetuje flag na false
2.	Sníží matches_remaining o 1 (min 0)
3.	Uloží do meta
4.	Pokud matches_remaining <= 0: zaloguje výzvu ke kliknutí na Train
_end_week_apply_training_and_advance()
Voláno po kliknutí na "Train" (tj. všechny zápasy jsou odehrány).
1.	Iteruje přes p.training_plan[0..3], volá p.add_xp_and_resolve(key, 1) pro každý slot
2.	Volá p.advance_week()
3.	Resetuje meta stav (aby nový týden vygeneroval nový počet zápasů)
4.	Volá znovu _ensure_week_state() pro nový týden
_refresh_ui()
Přepíše všechny labely aktuálním stavem. Klíčová logika tlačítka:
•	matches_remaining > 0 → text = "Simulate match", spustí MatchSim
•	matches_remaining <= 0 → text = "Train", spustí konec týdne
_on_confirm_week_pressed()
•	Pokud matches_remaining <= 0: volá _end_week_apply_training_and_advance()
•	Jinak: předá shooting skill přes GameManager.set_meta("match_sim_shooting_skill", skill) a přejde na MatchSimScreen
_build_attributes_text(p)
Sestaví BBCode text pro AttributesLabel:
•	Tréninkový plán (4 sloty s pretty-name)
•	TECH atributy s hodnotou a XP (Shooting: 32 (1/3xp))
•	MENTAL atributy (jen hodnota)
•	PHYS atributy (jen hodnota)
 
Edge Cases
Situace	Chování
player_data == null	UI zobrazí "No player data!", zápasy/tréninky jsou "-"
matches_remaining = 0 je načteno z meta	Validní stav, NEgeneruje nový týden
training_plan.size() != 4 na konci týdne	Zaloguje ERROR, přesto posune týden
Scéna reloadovaná uprostřed týdne (přechod z TrainingSreen)	Meta zachová stav, _ensure_week_state() ho obnoví
Přechod z MatchSim a zpět	META_RETURNED_FROM_MATCH zajistí správné odečtení jednoho zápasu
