# week_screen.gd — Dokumentace

## Přehled

Hlavní herní obrazovka. Zobrazuje aktuální stav hráče (týden, atributy, 
tréninkový plán) a řídí průběh týdne — simulaci zápasů a aplikaci 
tréninkového plánu. Je centrálním hubem mezi TrainingScreen a MatchSimScreen.

## Logika — flow

### _ready()
1. Připojí signály tlačítek
2. Volá _ensure_week_state()
3. Volá _apply_return_from_match_if_needed()
4. Volá _refresh_ui()

### _ensure_week_state()
Detekuje zda jsme v novém týdnu nebo jen reloadujeme scénu.
- Nový týden: vygeneruje matches_this_week = randi_range(1, 3), uloží do meta
- Stejný týden: načte uložené hodnoty z meta
- trainings_available = clampi(4 - matches_this_week, 0, 4)

### _apply_return_from_match_if_needed()
Pokud meta "ws_returned_from_match" = true:
1. Resetuje flag na false
2. Sníží matches_remaining o 1 (min 0)
3. Uloží do meta
4. Pokud matches_remaining <= 0: zaloguje výzvu ke kliknutí na Train

### _end_week_apply_training_and_advance()
Voláno po kliknutí na "Train" (tj. všechny zápasy jsou odehrány).
1. Iteruje přes p.training_plan[0..trainings_available-1]
   — aplikuje jen tolik slotů kolik je trainings_available (ne vždy 4!)
2. Volá p.advance_week()
3. Resetuje meta stav
4. Volá _ensure_week_state() pro nový týden

### _refresh_ui()
Přepíše všechny labely aktuálním stavem.
- ClassLabel zobrazuje: jméno hráče, název týmu, classa (3 řádky)
- matches_remaining > 0 → tlačítko = "Simulate match"
- matches_remaining <= 0 → tlačítko = "Train"

### _on_confirm_week_pressed()
- Pokud matches_remaining <= 0: volá _end_week_apply_training_and_advance()
- Jinak: předá shooting skill přes meta a přejde na MatchSimScreen

---

## Edge Cases

| Situace | Chování |
|---|---|
| player_data == null | UI zobrazí "No player data!" |
| matches_remaining = 0 načteno z meta | Validní stav, NEgeneruje nový týden |
| training_plan.size() != 4 na konci týdne | Zaloguje ERROR, přesto posune týden |
| trainings_available = 0 | Žádný trénink se neaplikuje (viz technický dluh) |
| Scéna reloadovaná uprostřed týdne | Meta zachová stav |

## Technický dluh

1. [HIGH] trainings_available může být 0 — bible říká minimum je vždy 1 trénink. Zvažit návrat k maxi(4 - matches, 1) nebo vědomě změnit pravidlo v bibli.
2. [MEDIUM] Metoda _generate_new_week() existuje v kódu ale není nikde volána — mrtvý kód, lze smazat.
3. [LOW] Shooting je jediný atribut vstupující do zápasové simulace.
