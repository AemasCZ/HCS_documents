PlayerData.gd — Dokumentace
Přehled
Centrální datový resource hry. Drží veškerá data jednoho hráče — identitu, atributy, XP, tréninkový plán a časovou progresi. Přistupuje se k němu výhradně přes GameManager.player_data. Neobsahuje žádnou UI logiku.
 
Soubor
●	Soubor: res://resources/PlayerData.gd
●	Typ: Resource (class_name PlayerData)
●	Stav: 🟢 Implementováno (MVP verze)

Metody
Setup & inicializace
setup(p_name: String, p_class: String) -> void
Hlavní inicializace nového hráče. Volá se z GameManager.new_game().
Flow:
1.	Uloží jméno a classu
2.	Resetuje časovou progresi na týden 1, měsíc 1, sezóna 1
3.	_initialize_attributes() — nastaví všechny atributy na BASE_ATTR_VALUE (25), XP na 0
4.	_apply_class_baseline() — přepíše hodnoty podle classy (TEST hodnoty)
5.	_initialize_training_plan() — nastaví 4 sloty na shooting jako výchozí
_initialize_training_plan() -> void
Výchozí plán = 4× ATTR_SHOOTING. Hráč ho mění na TrainingScreen.
 
Atributové API
get_attr_value(key: String) -> int
Vrátí aktuální hodnotu atributu. Fallback: BASE_ATTR_VALUE pokud klíč neexistuje.
set_attr_value(key: String, value: int) -> void
Nastaví hodnotu atributu s clampem na [ATTRIBUTE_MIN, ATTRIBUTE_MAX].
get_attr_xp(key: String) -> int
Vrátí aktuální XP atributu. Fallback: 0.
set_attr_xp(key: String, value: int) -> void
Nastaví XP atributu. Minimálně 0 (negativa nejsou povolena).
add_xp_and_resolve(key: String, amount: int) -> int
Přidá XP a automaticky provede level-upy. Vrátí počet level-upů (pro UI feedback).
Flow:
1.	Přidá amount k attr_xp[key]
2.	Dokud xp >= XP_PER_LEVEL (3): odečte 3 XP, zvýší atribut o 1
3.	Pokud atribut dosáhl ATTRIBUTE_MAX (99): XP se smaže, loop se ukončí
4.	Vrátí celkový počet level-upů
 
Časová progrese
advance_week() -> void
Posune hru o jeden týden. Volá se z WeekScreen.
Flow:
1.	current_week += 1
2.	Pokud překročí WEEKS_PER_SEASON (26): reset na 1, current_season += 1
3.	Přepočítá current_month z aktuálního týdne (floor((week-1)/4)+1, cap na 6)
 
Utility
get_available_trainings(matches_this_week: int) -> int
Vrátí počet dostupných tréninkových slotů pro daný týden.
Vzorec: max(4 - matches_this_week, 1)
Zápasy tento týden	Dostupné tréninky
0	4
1	3
2	2
3	1
4+	1 (minimum)
Odpovídá HCS Bible — Core Loop: tréninky a zápasy se navzájem omezují, minimum je vždy 1 trénink.
 
Edge Cases
Situace	Chování
Atribut na hodnotě 99, přidáme XP	XP se smaže, level-up se neprovede
get_attr_value s neznámým klíčem	Vrátí BASE_ATTR_VALUE (25) — safe fallback
add_xp_and_resolve s amount = 0	Vrátí 0 level-upů, žádná změna
advance_week() na konci sezóny	Reset týdne na 1, sezóna +1, měsíc přepočítán správně
Záporné XP	maxi(value, 0) zajišťuje minimum 0
 
Závislosti
Žádné externí závislosti. PlayerData je čistý datový objekt — neví nic o UI ani o GameManageru.
